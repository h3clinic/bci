# Vendor Capability Evidence

Store evidence that your chosen PCB vendor can perform IPC-4761 Type VII
VIPPO (epoxy plug + copper cap) for:

- Drill: 0.200 mm
- Pad:   0.400 mm
- Board: 4-layer, 1.6 mm, FR4

## Required evidence (at least one):

- Email confirmation from vendor CAM engineer (PDF export)
- Screenshot of vendor capability page showing Type VII
- Order line item or quote showing VIPPO selected
- Vendor datasheet for via fill process

## Naming convention:

    <vendor>_<YYYYMMDD>_vippo_capability.<ext>

Example:
    jlcpcb_20260301_vippo_capability.pdf
    pcbway_20260315_vippo_capability.png

## Required keywords in evidence:

At least one file must contain references to:
- Type VII (or IPC-4761 Type VII)
- Epoxy plug (or via fill)
- Copper cap (or cap plating)
- Via-in-pad
